# Ubuntu arm64 VM validation — 2026-10-27

Historical evidence recorded under the earlier dual-architecture plan. On 2026-10-28,
the user changed support to Apple Silicon only; any Intel prerequisites below are
superseded by the current [acceptance ledger](phase-1-acceptance.md).

Result: all four existing test suites passed when executed natively in the
user-designated UTM Ubuntu Server guest over SSH. This is portable/Linux
validation, not macOS provider compatibility or release acceptance.

- Guest: Ubuntu 26.10, `uname -sm` returned `Linux aarch64`.
- Guest had `tar`, but neither Go nor gcc was found on PATH.
- Builder: `go version go1.27.3 darwin/arm64` on the development Mac.
- No toolchain, package manager or other dependency was installed in the guest.
- The current working tree was tested; it is not a tagged release.
- Source snapshot SHA-256: `42b227289d3467659b40c647bdb48d31533c7840c34b949a2bf0d4ca451a85fd`.
  Computed by concatenating each relative path, NUL, file bytes, NUL for go.mod,
  sorted cmd/**/*.go, sorted internal/**/*.go, then sorted regular files directly
  in internal/providers/brew/testdata. Documentation outside that fixture folder
  is excluded.
- Transferred test bundle SHA-256:
  `322839501e6c1f516c90d450b08128f35afa296773d7c969be89672c8e2c565b`.
  Independently checked on the guest before extraction. This is a temporary test
  bundle checksum, not a distribution or Homebrew source checksum.

## Procedure and observed outcomes

Cross-compiled each package's tests on the Mac with:

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go test -c -o BINARY PACKAGE
```

| Package | Native guest invocation, from package directory | Result |
| --- | --- | --- |
| internal/cli | `./cli.test -test.v -test.timeout=120s` | PASS |
| internal/process | `./process.test -test.v -test.timeout=120s` | PASS |
| internal/providers/brew | `./brew.test -test.v -test.timeout=120s` | PASS |
| internal/release | `./release.test -test.v -test.timeout=120s` | PASS |

Copied the Homebrew testdata beside its test executable. Fake process and
Homebrew tests re-executed these Linux binaries with isolated PATH/HOME/prefix;
no live package-manager update command was run. Tested cancellation, child
signals, descendant termination/grace, bounded output, consent, partial failures,
check-only behavior, cleanup and release archive/source validation.

Also built the CLI with `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath`:

- `--version`: exit 0, `upmacx dev`.
- `--help`: exit 0 and expected usage/provider limitations.
- No arguments: exit 1, empty stdout, exact stderr
  `execution requires macOS and a non-root user`.

The SSH validation command exited 0 after asserting the expected refusal.
Extraction produced benign Apple metadata warnings and future timestamp warnings
from guest clock skew; extraction and all checks succeeded. Temporary test files
were left in the guest for inspection. Credentials and account/network details
are intentionally absent from this record.

## Limits and next gates

No Linux-side `go test` compilation, race detector, vet, formatting or Darwin
cross-build ran in the guest because its Go toolchain/C compiler were absent.
The precompiled test executables themselves ran natively, including their fake
child processes. Mac-side build/check evidence is separate in
[progress](../specs/08-progress.md).

Linux remains an unsupported updater platform. Real macOS Homebrew discovery,
controlled formula/cask upgrades, interactive installer behavior, native Intel
execution, formula audit/install/test and hosted release workflow validation
remain pending. No public release or compatibility claim follows from these
Linux test results.

`internal/providers/brew` suites natively in the same Ubuntu guest. Both returned
`PASS`, and the enclosing SSH validation exited 0. The follow-up bundle SHA-256
is `e024e327646c3691c8819748398b7cc4126234bbfe221a7234b652165bf39d2f`; this
is a separate bundle from the original full run above. It used plain USTAR entries

development Mac, not inside Ubuntu.

New regressions cover signal notification when an interrupted leader leaves
descendant output pipes open, and Homebrew capability-probe runtime errors. The
